虾皮台湾选品录制器（纯浏览器扩展版 v3.2.2）
============================================

这是一个独立的浏览器扩展，完全不依赖本地录制器或调试端口。
开启后自动录制你在跨境卫士（或任何 Chromium 浏览器）虾皮买家端浏览到的商品，
并直接同步到你自己的 GitHub 仓库（网站数据源）。

【v3.2.2 更新 · 2026-09-11】
- 「录完这一页」提速：不再每滚一步死等 1.2 秒。
  · 旧写法固定等 1200ms，而虾皮懒加载通常 200~600ms 就回来了 —— 一页 20 批白等 20 秒以上。
  · 现改为「盯着页面高度」：每 150ms 探一次，新内容一进来立刻滚下一步；没进来则最多等满 1200ms。
    所以**慢的时候与旧版耗时完全相同，快的时候成倍提前**（实测逻辑等待省 40% 以上）。
  · 三重上限（连续 3 次不增高 / 120 步 / 90 秒）与「录制开关一关立即停」一个都没动。
- 录制过程新增实时进度：浮窗显示「第 N 步 · 本轮新增 M 件 · 已用 T 秒」，
  结束时显示「✅ 录完这一页：新增 N 件（月销≥30 的 M 件）· 用时 T 秒」。
  此前全程无提示，用户会以为卡死了、手动去点导致录制被打断。
- 新增速度断言（反向验证过：把循环还原成旧的固定 1200ms，3 项立刻转红）。

【v3.2.1 更新 · 2026-09-11】
- 修复「录完这一页」的两个缺陷（都是新增行为测试挖出来的）：
  ① 店铺页（本功能唯一的目标页）的「新增 N 件」一直显示 0 件。
     原因：计数用的是「本次会话新增 key」差集，而店铺页走的是 isUpdate=true 那条路，
     根本不会记入那个集合。现改为独立计数器，且同一件只算一次、月销取最大值。
  ② 在搜索页 / 每日发现页点它，会白滚一遍然后说「这一页已经录过了」—— 而这些页面根本不录。
     现改为白名单：只有店铺页与商品详情页才允许，其余页面一次都不滚、直接告诉你该去哪儿用。
- 新增「行为测试」（jsdom 真跑一遍自动滚动过程，22 项）：验证真的滚到底、真的停得下来、
  真的把件数算对。以上两个缺陷都已做过反向验证（把修改还原成错误写法，测试立刻转红）。

【v3.2.0 更新 · 2026-09-11】
- 新增「📄 录完这一页」按钮：点一下自动滚到底，把当前页面上的商品全部加载出来再录，
  不用再手动滚、也不会因为滚太快漏掉中间整批（列表是分批懒加载的）。
  · 只做「等价于人手动滚动」这一个动作：不点页面上的按钮、不发任何额外请求，
    风控面与你手动滚完全一样。
  · 三重安全上限：连续 3 次页面不再变长即判定到底 / 最多 120 步 / 总耗时不超过 90 秒。
  · 想中途停：把「录制开关」拨掉，立刻停。
  · 完成后面板会告诉你「新增 N 件，其中月销≥30 的 M 件」。
- ⚠️ 录制范围（此前文档写错了，特此更正）：只有「店铺页」和「商品详情页」会被录制。
  搜索页 / 每日发现 / 首页**不录制**（2026-08-25 起因噪音大而关闭）。
  在搜索页点「录完这一页」会明确提示你改去店铺页，不会假装成功。
- 「月销 ≥ 30」仍由网站端执行：录到的商品**全部保留**（原始数据不丢，以后想放宽门槛还能捞回来），
  网站上只显示月销 ≥ 30 的；可在网站「月销门槛」下拉里改成 100 或 0。

【v3.1.9 更新 · 2026-09-10】
- 新增「商品价格区间」采集：多规格商品会记录最高价 price_max，
  网站上显示成「NT$100–200」；单一价格商品不显示区间（绝不伪造）。
  上下限相等、或上限不高于下限的脏数据一律忽略。
- 录制字段确认：月销 / 总销量 / 价格区间 / 主图（另带名称、店铺用于展示）。
- 「月销<30 不进入网站」由网站端执行（见网站「月销门槛」下拉），
  录制器仍照常记录全部商品，原始数据不丢，随时可以放宽门槛看到。

────────────────────────────────────────
一、加载扩展（只需一次）
────────────────────────────────────────
1. 在浏览器地址栏输入：chrome://extensions
2. 右上角打开「开发者模式」（開發人員模式）
3. 点击左上角「載入未封裝項目」
4. 选择本文件夹（包含 manifest.json 的 ext 文件夹）
5. 加载成功后，工具栏会出现扩展图标「🛒 虾皮选品录制器」

⚠️ 若你之前加载过旧版扩展「Shopee 选品录制（本地回传）」，请先在那页点「移除」删除，再加载本文件夹。

────────────────────────────────────────
二、填写 GitHub 配置（只需一次）
────────────────────────────────────────
1. 右键工具栏的扩展图标 → 「选项」（或点开面板里的「⚙ 设置」）
2. 填写：
   - GitHub Token（必填）：需要 repo 权限的 Personal Access Token
     （项目目录里的 sync_config.json 中 ghp_ 开头那串就是；复制粘贴进来）
   - 仓库所有者：23ccf
   - 仓库名：shopee-sync
   - catalog 路径：catalog.json
   - sync 路径：sync.json
3. 点「保存配置」

────────────────────────────────────────
三、开始录制
────────────────────────────────────────
1. 点击浏览器工具栏的扩展图标 → 弹出面板
2. 把「录制开关」拨到开启（红色 ● 录制中）
3. 在浏览器里打开虾皮买家端页面：
   ✅ 会录制：店铺页（https://shopee.tw/shop/... 或 https://shopee.tw/店铺名）
             商品详情页（https://shopee.tw/...-i.店铺ID.商品ID）
   ❌ 不录制：搜索页、每日发现、首页（这些页面噪音大，2026-08-25 起关闭）
4. 两种录法，任选：
   · 手动浏览 / 翻页 —— 扩展自动抓取
   · 点面板里的「📄 录完这一页」—— 自动滚到底，把整页 / 整店加载完再录
     （推荐：不漏件，一页约 20 秒；滚动期间请不要同时手动操作该页面）
   - 面板里「待同步商品」数字会增长
   - 每 30 秒自动同步一次到网站
5. 想立刻同步：点面板里的「⚡ 立即同步」

关闭开关即停止录制（不再抓取、不再同步）。

────────────────────────────────────────
四、在网站查看
────────────────────────────────────────
打开网站：https://23ccf.github.io/shopee-site/
- 「📦 全部商品」：按默认月销量降序，显示所有录制到的商品，支持简繁/大小写互通搜索
- 「📊 行业大盘」「🏆 榜单」「🏪 店铺」：价格带、品类、爆品与店铺维度分析
- 「📈 销售追踪」：每天点一次「记录今日快照」，就能算出每日真实增量与采购建议
- 「🧭 选品洞察」：选品打分（S/A/B/C 分档）、跨店同款比价、价格趋势
- 点网站右上角「🔄 立即同步」按钮可立即拉取最新数据

注意：GitHub 有数分钟 CDN 缓存，点「立即同步」后若没变化，稍等 1~3 分钟再点一次。
若该地址打不开，说明它被换掉了，请到 https://github.com/23ccf/shopee-site 的 README 查看最新地址。

五、文件说明
────────────────────────────────────────
manifest.json      扩展配置
background.js       后台：状态/存储/同步 GitHub
inject.js           页面主环境嗅探（偷听虾皮自己发出的接口，拿到真实月销/总销/价格）

bridge.js           网站 ↔ 扩展 桥接（隔离世界）
bridge_main.js      网站 ↔ 扩展 桥接（主世界）
popup.html/js       工具栏面板（录制开关、录完这一页、立即同步）
options.html/js     设置页（GitHub 配置）
