虾皮台湾选品录制器（纯浏览器扩展版 v2.0）
============================================

这是一个独立的浏览器扩展，完全不依赖本地录制器或调试端口。
开启后自动录制你在跨境卫士（或任何 Chromium 浏览器）虾皮买家端浏览到的商品，
并直接同步到你自己的 GitHub 仓库（网站数据源）。

────────────────────────────────────────
一、加载扩展（只需一次）
────────────────────────────────────────
1. 在浏览器地址栏输入：chrome://extensions
2. 右上角打开「开发者模式」（開發人員模式）
3. 点击左上角「載入未封裝項目」
4. 选择本文件夹（包含 manifest.json 的 ext 文件夹）
5. 加载成功后，工具栏会出现扩展图标「🛒 虾皮选品录制器」

⚠️ 若你之前加载过旧版扩展「Shopee 选品录制（本地回传）」，请先在那页点「移除」删除，再加载本文件夹。

────────────────────────────────────────
二、填写 GitHub 配置（只需一次）
────────────────────────────────────────
1. 右键工具栏的扩展图标 → 「选项」（或点开面板里的「⚙ 设置」）
2. 填写：
   - GitHub Token（必填）：需要 repo 权限的 Personal Access Token
     （项目目录里的 sync_config.json 中 ghp_ 开头那串就是；复制粘贴进来）
   - 仓库所有者：23ccf
   - 仓库名：shopee-sync
   - catalog 路径：catalog.json
   - sync 路径：sync.json
3. 点「保存配置」

────────────────────────────────────────
三、开始录制
────────────────────────────────────────
1. 点击浏览器工具栏的扩展图标 → 弹出面板
2. 把「录制开关」拨到开启（红色 ● 录制中）
3. 在浏览器里打开虾皮买家端任意页面：
   https://shopee.tw/daily_discover
   https://shopee.tw/search?keyword=...
   商品详情页、店铺页等
4. 浏览 / 翻页，扩展会自动抓取商品
   - 面板里「待同步商品」数字会增长
   - 每 30 秒自动同步一次到网站
5. 想立刻同步：点面板里的「⚡ 立即同步」

关闭开关即停止录制（不再抓取、不再同步）。

────────────────────────────────────────
四、在网站查看
────────────────────────────────────────
打开网站：https://2dadfac111d24788a31b60fd763469b5.bj8.agentos-app.net
- 「📦 全部商品」：按默认月销量降序，显示所有录制到的商品
- 「📅 今日录制」：当天（台北时间）首次录到的商品
- 点网站右上角「🔄 立即同步」按钮可立即拉取最新数据

注意：GitHub 有数分钟 CDN 缓存，点「立即同步」后若没变化，稍等 1~3 分钟再点一次。

────────────────────────────────────────
五、文件说明
────────────────────────────────────────
manifest.json      扩展配置
background.js       后台：状态/存储/同步 GitHub
content-main.js     抓取虾皮页面商品（主世界）
content-bridge.js   数据桥接（隔离世界）
popup.html/js       工具栏面板（录制开关）
options.html/js     设置页（GitHub 配置）
