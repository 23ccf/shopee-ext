## 中文（zh-CN / zh-TW）

**标题**
```
虾皮台湾选品录制器 - 商品数据采集与同步
```

**简短描述**
```
浏览虾皮台湾商品时自动录制价格、销量等数据，同步到选品网站，支持跨端删除。
```

**详细描述**
```
这是一款面向台湾市场跨境电商选品的浏览器扩展，配合选品网站使用。

【核心功能】
· 自动录制：浏览虾皮台湾商品页、店铺页、搜索/列表页时，自动抓取商品名称、价格、月销量、总销量、周销量、评分、评价数、图片等信息。
· 定时同步：录制到的商品自动推送回你的数据源，无需手动导出。
· 删除同步：在网站上删除某件商品后，录制器不会再重复录入，杜绝「删了又出现」。
· 月销口径统一：正确区分「月销量 / 累计总销量 / 周销量」，避免把历史总销量误当本月销量。

【使用方式】
1. 安装后在扩展设置页填入 GitHub Token（或自建后端）。
2. 打开扩展开启录制，正常浏览虾皮台湾商品即可。

【数据说明】
本扩展只在虾皮台湾页面采集你「正在浏览」的商品公开信息，不采集账号密码、支付信息等隐私数据。数据只会同步到你本人配置的数据源（GitHub 仓库或你自己的后端），不会上传到任何第三方服务器。

【注意】
本扩展不提供账号、不提供商品数据；它只是一个采集与同步工具，商品数据来自你本人的浏览行为。
```

## English

**Title**
```
Shopee TW Product Recorder - Data Capture & Sync
```

**Short description**
```
Auto-capture price, sales and product data while browsing Shopee Taiwan, synced to your dashboard.
```

**Detailed description**
```
A browser extension for Taiwan-market cross-border e-commerce product research, working together with the product-selection dashboard.

【Features】
· Auto-capture: while browsing Shopee Taiwan product pages, shop pages and search/listing pages, it automatically grabs product name, price, monthly sales, total sales, weekly sales, rating, review count, images, etc.
· Scheduled sync: captured products are automatically pushed back to your data source — no manual export needed.
· Delete-sync: after you delete a product on the dashboard, the recorder will not re-add it (no more "deleted but comes back").
· Unified sales metrics: correctly distinguishes monthly / cumulative / weekly sales so historical total sales are never mistaken for this month's sales.

【Usage】
1. After installing, fill in a GitHub Token (or a self-hosted backend) on the options page.
2. Open the extension, enable recording, and browse Shopee Taiwan products as usual.

【Data】
This extension only captures public product information from pages you are actively browsing. It does not collect account credentials, payment info or other private data. Captured data is synced only to the data source you configured (your GitHub repo or your own backend) — never to any third-party server.

【Note】
This extension provides no account and no product data; it is only a capture & sync tool, and all product data comes from your own browsing.
```
