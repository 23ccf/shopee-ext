⚙ 虾皮选品录制器 — 设置

录制器会把商品同步到你自己的后端（网站数据源）。如果你仍想用 GitHub，请关闭「使用自建后端」。

开启后，扩展通过账号密码登录后端，直接把商品写入后端数据库，无需 GitHub Token。这是开源给他人使用的推荐方式。
你部署的后端地址，例如 CloudStudio 给你的 URL。
需要 repo 权限的 Personal Access Token。仅保存在本机扩展内，不会外传。

🇨🇳 Gitee 镜像（国内实时同步，可选）

Gitee 在国内可直连，开启后扩展会同时把数据推一份到 Gitee，网站改读 Gitee，做到真正实时、不受 GitHub 封锁影响。需要：①在 gitee.com 建一个公开仓库；②在「设置-私人令牌」生成带 projects 权限的 token。

仅保存在本机扩展内，不会外传。

💡 Token 不会丢：保存后 token 存在本机扩展，点扩展卡片上的「重新加载」不会清空；只有「移除」扩展才会清空（需重填）。
💡 价格循环：若发现网站价格又变大 10 倍，多半是旧待同步队列里残留了错价。点上方「🗑 清空待同步」清掉，再重新浏览录制即可；新录商品已是正确价格。
